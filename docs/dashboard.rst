Dashboard
=========

The interactive dashboard turns the locally stored time entries into a set
of views of your working time.

Open it from the command line:

.. code-block:: console

   stanwell dashboard

The date controls in the dashboard determine the period used for most
analyses.

Overview
--------

The Overview brings together the main working-time measures.

It shows recorded and required working time, working-time balance and
overtime compensation. Daily and weekly views make shorter-term variation
visible, while the longer-term balance view shows how additional work,
shortfalls and overtime compensation affect the accumulated balance.

The Overview also provides a weekday view to help identify differences in
working time across the week.

Projects
--------

The Projects tab shows how recorded working time is distributed between
projects.

This is useful for understanding where working time has gone during the
selected period rather than considering total working hours alone.

Working patterns
----------------

The Working patterns tab focuses on when work takes place.

It helps make patterns such as work outside core hours and work on
designated days off visible. These measures complement the simple
working-time balance: working the expected number of hours does not
necessarily mean those hours are distributed in a healthy way.

Tag balance
-----------

The Tag balance tab uses tags attached to Toggl entries to explore categories
of activity across the selected period.

Tags can overlap, so tagged time should be interpreted as different views of
the same recorded time rather than necessarily additive categories.
