Command-line interface
======================

The ``stanwell`` command is used to set up Stanwell,
maintain the local copy of your Toggl data and launch the dashboard.

Commands
--------

.. cli-commands::

Use the built-in help at any time:

.. code-block:: console

   stanwell --help

Help for an individual command is available in the same way:

.. code-block:: console

   stanwell COMMAND --help
